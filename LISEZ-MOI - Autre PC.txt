======================================================================
  ATELIER FIRMWARE — DOSSIER COMPLET POUR TRANSFERT SUR UN AUTRE PC
======================================================================

Ce dossier contient la totalité de l'application et de ses outils :
  - atelier-firmware\   (l'application et son interface web)
  - moria\              (outil d'extraction de firmware)
  - mithril\            (outil d'inspection et recherche de failles/secrets)
  - cpu_rec\            (détection d'architecture processeur)
  - binbloom\           (analyse d'adresse de chargement / UDS)
  - binwalk\            (analyse d'entropie et signatures)
  - bulk_extractor\     (traces : VIN, GPS, téléphones, e-mails, adresses MAC)
  - findcrypt-yara\     (règles yara : tables de chiffrement)
  - Rapports-Analyses-Sauvegarde\ (vos analyses existantes sauvegardées)

IMPORTANT : Gardez tous ces sous-dossiers ensemble dans le même dossier parent,
car Atelier Firmware cherche automatiquement moria, mithril, cpu_rec, binbloom,
binwalk, bulk_extractor et findcrypt-yara à côté du dossier "atelier-firmware".

Si vous avez récupéré ce dossier depuis GitHub, les outils et les rapports n'y
sont pas inclus. Clonez les outils à côté de "atelier-firmware" (depuis ce dossier) :

   git clone https://github.com/nicolasnt3-a11y/moria
   git clone https://github.com/nicolasnt3-a11y/mithril
   git clone https://github.com/airbus-seclab/cpu_rec
   git clone https://github.com/quarkslab/binbloom
   git clone https://github.com/ReFirmLabs/binwalk
   git clone https://github.com/simsong/bulk_extractor
   git clone https://github.com/polymorf/findcrypt-yara

Puis, dans chacun de ces dossiers, déclarez le dépôt officiel (utilisé pour les
mises à jour) : git remote add upstream <même adresse> ; git fetch upstream ;
git remote set-head upstream -a

----------------------------------------------------------------------
  COMMENT L'UTILISER SUR L'AUTRE PC ?
----------------------------------------------------------------------

1. Prérequis sur le nouveau PC :
   - Python 3 installé sous Windows (avec l'option "Add Python to PATH" cochée)
   - Git pour Windows (https://git-scm.com/)
   - WSL avec Ubuntu installé (commande : wsl --install -d Ubuntu)

2. Installation en un clic :
   - Placez ce dossier où vous voulez sur le nouveau PC (ex: C:\Users\...\projets\
     ou directement sur le Bureau).
   - Double-cliquez sur "Installer sur le nouveau PC.bat" :
     -> Cela créera le raccourci "Atelier Firmware" sur le Bureau du nouveau PC
     -> Cela copiera vos anciens rapports d'analyse dans Documents\Atelier Firmware

3. Premier lancement sur le nouveau PC :
   - Lancez "Atelier Firmware" depuis le Bureau (ou via "Lancer Atelier Firmware.bat").
   - Dans la page web qui s'ouvre, allez dans l'onglet « Outils » et cliquez sur :
     * « Installer » (compile moria, mithril, cpu_rec, binbloom, binwalk,
       bulk_extractor et installe yara dans Ubuntu
       et télécharge la base de failles CVE)
     * « Installer Ghidra » (facultatif, si vous utilisez la rétro-ingénierie)
